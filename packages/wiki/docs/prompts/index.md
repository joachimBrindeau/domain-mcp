# MCP prompts

Reusable workflows exposed through the Model Context Protocol.

- [`domain-audit`](/docs/prompts/domain-audit) — Audit all domains for expiration, DNS, and security settings
- [`dns-setup`](/docs/prompts/dns-setup) — Interactive DNS configuration for a domain
- [`domain-brainstorm`](/docs/prompts/domain-brainstorm) — Find available domains for a product or tool
- [`bulk-renewal`](/docs/prompts/bulk-renewal) — Review and manage domain renewals
